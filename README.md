# sloffer-backend

.NET + PostgreSQL backend for **Sloffer**, a personal tool that pulls job listings from public (no-auth) sources, uses AI to match them to the owner, and serves them to the web UI.

Not scaffolded yet. Work arrives as ClickUp tasks (`Agent = Backend`) and is implemented by the `implement-task` skill via [sloffer-watcher](https://github.com/revazza/sloffer-watcher).
